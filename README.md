### 开源项目

- [轻小说文库下载器](https://github.com/mj3622/Wenku8Downloader)<br>
  用来搜索和下载轻小说，支持按卷导出 EPUB、保存插图和管理下载任务。

- [轻小说更新提醒](https://github.com/mj3622/NoveliaReminder)<br>
  定时检查收藏小说有没有更新，有新章节时通过邮件或飞书发送提醒。

- [EPUB 合并工具](https://github.com/mj3622/epub-merger)<br>
  直接在浏览器中调整书籍顺序并合并 EPUB，整个过程不需要上传文件。

- [简繁转换助手](https://github.com/mj3622/simplified-traditional-converter)<br>
  批量将 TXT 和 EPUB 文件从繁体中文转换为简体中文。
